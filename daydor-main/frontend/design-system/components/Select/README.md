# Select

Picks one value from a short known list — most often, who to delegate a decision to.

**Consumer provides:** `label`, `options` (strings or `{value, label, disabled}`), `value`/`onChange` or `defaultValue`; optional `placeholder`, `hint`, `error`.

- More than ~10 options or a list of people to search → shadcn `Command` combobox styled with the same tokens.
