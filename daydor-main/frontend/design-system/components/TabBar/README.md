# TabBar

Bottom navigation on phones, with **Ask** as the raised centre tab.

**Consumer provides:** `items` (`{label, icon, href?, active?, count?, primary?}`) — five at most.

- Founder: Home · Decisions (count) · **Ask** · People · More.
- Employee: Home · Pay · **Ask** · Leave · Me (own details, benefits, documents). Expense claims start from Home or Ask. In a client theme, the centre tab and the active icon take the client's `action` colour.
- Only Decisions carries a count. Labels are always visible.
