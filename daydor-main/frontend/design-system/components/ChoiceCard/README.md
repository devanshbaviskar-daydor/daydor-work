# ChoiceCard

A selectable card with its settings inside, for configuration a founder does rarely — like choosing which group benefits to offer.

**Consumer provides:** `title`, `selected`, `onToggle(checked)`; optional `description`, `icon`, `meta` (estimated cost, or "Not offered"), `children` (fields shown only when selected — usually two-column `Select`s).

- Use for small closed sets (GMC, GPA, GTL) — never as a marketplace or a long list.
- Show the estimated cost on the card and a running total beside the list, so the commitment is visible before anything is sent.
