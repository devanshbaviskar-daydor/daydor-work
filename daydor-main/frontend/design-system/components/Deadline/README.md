# Deadline

A due date in relative words and an absolute date, coloured by urgency.

**Consumer provides:** `daysLeft` (negative when overdue), optional `date` ("15 Nov").

- Muted when more than 3 days away, warning within 3 days, danger when overdue.
- Statutory deadlines (PF 15th, ESI 15th, TDS 7th, PT by state) always show both forms: "Due in 2 days · 15 Nov".
