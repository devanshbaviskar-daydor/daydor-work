# DocumentPage

The A4 frame for every generated document — offer letters, appointment and relieving letters, experience certificates, F&F statements, the cover sheet for Form 16.

**Consumer provides:** `company`, `title`, `children` (paragraphs, `dd-doc-h` section heads, `dd-doc-table` tables); optional `address`, `meta` (date and reference number), `footer` (legal line: CIN, signing instructions), `logo`, `theme` (the client's theme id).

- Client letterhead on top (logo, name, address, an `action`-coloured rule). Daydor appears only in the footer.
- Write letters in the content voice: warm, plain, specific. Compensation always as an annexure table, with the wage-definition note (basic ≥ 50% of CTC).
- Form 16 Part A is generated by TRACES and must be issued as-is; Daydor adds only a one-page cover summary in this frame, never a redesigned Form 16.
- Always light paper; `@media print` removes the border and shadow and sets A4 margins.
