# WriteClass

Labels how consequential an agent action is, using the three write classes from the architecture spec.

**Consumer provides:** `level` — `read` (Read-only: eye, muted), `guarded` (Reversible: shield, info), `irreversible` (Irreversible: lock, the `irreversible` colour on its soft ground); optional `iconOnly`.

- Irreversible is the only loud label in the product. Use it on every decision, step or button that moves money, files with a government portal or revokes access.
- Don't label read-only actions unless contrasting them with writes (e.g. inside a Receipt).
