# Avatar

Daydor's mark in the conversation (a teal disc with a lowercase d) or a person's initials.

**Consumer provides:** `kind` (`'daydor'` default or `'person'`), `name` for people, `size` (default 28), `live` to pulse while Daydor is working.

- There is one agent avatar. Domains and workers never get their own faces.
- People get initials on surface-sunken; use photos only if the person uploaded one.
