# EmptyState

What to show when there's nothing — either nothing yet (first run) or nothing right now (no decisions).

**Consumer provides:** `title`, `children` (one or two sentences), optional `icon`, `action` (one Button), `size` (`sm` inside the rail).

- First run is a conversation starter, not a form: "Let's set up Acme Labs — share your last payroll register and I'll build everyone's profile from it. You'll review it before anything is saved."
- "Nothing needs you" is a good state: say so plainly and promise to surface the next decision. No illustrations.
