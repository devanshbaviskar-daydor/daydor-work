# SourceChip

A small chip naming what an agent relied on: a data set, a document or a law.

**Consumer provides:** `label`, `kind` (`data`, `doc`, `law`), optional `href` to open it.

- Name sources the way a person would: "Attendance · Oct 2026", "ESI Act 1948, s.2(12)" — not table names.
- Laws cite the Act and section, so a founder can forward it to their CA.
